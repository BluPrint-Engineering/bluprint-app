# The admin invites managers and assistants

Amends [0023](0023-invitation-hierarchy.md).

The organization admin invites managers and assistants alike. A manager still invites only assistants, and an assistant invites nobody. The admin configures every project, its team included ([0067](0067-admin-configures-any-project-through-the-organization.md)), so a project the admin set up does not wait for a manager before its first assistant can join.

Requirements: RF-126

## Considered Options

- **The admin invites managers only** (0023): an admin setting up a project with no manager yet could not bring its assistants in.
