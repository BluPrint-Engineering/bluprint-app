# Contractor follows the role pattern: a default per unit and discipline, overridden on the pin

A contractor has a default per unit + discipline and can be overridden on an individual pin without touching the default. The default is filled unit by unit, because in practice each unit has its own contractor per discipline; there is no project-wide default, and the absence of a row is what the dashboard shows as "no contractor".

Requirements: RF-302, RF-303, RF-305, RF-307
